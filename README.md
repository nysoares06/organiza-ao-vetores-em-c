# Organização de Vetores em C

## Sobre o projeto
Programa em C que reorganiza um vetor, colocando os números pares no início e os números ímpares no final, sem utilizar um vetor auxiliar.

## Conceitos praticados
- Linguagem C
- Vetores
- Funções
- Laços de repetição
- Estruturas condicionais

## Como executar
Compile o programa utilizando o GCC:

    gcc main.c -o programa

Execute o programa:

    ./programa
